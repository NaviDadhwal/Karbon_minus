# Auto Git Push Rule

Whenever you make any changes to the codebase, fix bugs, add new features, or update configuration:
1. Verify the project builds properly if applicable (`npm run build`).
2. Automatically commit the changes with a concise, descriptive commit message.
3. Automatically push the commit to the remote GitHub repository (`git push origin main` or current tracking branch).
4. Inform the user of the commit hash and push status.
